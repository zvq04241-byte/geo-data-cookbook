# mof / direct_investment

## 何をする

財務省が公表する **直接投資残高（地域別・業種別）** から、日本の対外／対内直接投資残高を
地域別・国別・業種別に取る。認証不要。

共通テストの「日本の対外直接投資残高の地域別割合の変化」（2015年追試Ａ第2問問4ほか）は
この系列。JETRO の統計も元をたどればここ。

## 取得

```
2019〜2023年  https://www.mof.go.jp/policy/international_policy/reference/iip/dip<年>.xlsx
2024年以降    https://www.mof.go.jp/policy/international_policy/reference/iip/data/dip<年>.xlsx
```
**★2024年からURLに `data/` が挟まる。** 掲載ページ（`.../iip/data/index.htm`）から拾うのが安全。

```bash
python fetch.py --years 2019-2025                     # 対外・地域別の時系列
python fetch.py --years 2025 --direction inward       # 対内
python fetch.py --years 2025 --level country          # 国別
```

## シートの構成

| シート | 中身 |
|---|---|
| `1` | **対外**直接投資残高（Outward） |
| `2` | **対内**直接投資残高（Inward） |

行は「合計 → アジア → （中華人民共和国・香港…）→ 北米 →（アメリカ合衆国・カナダ）→ …」と
**地域の下に国がぶら下がる**。A列に地域、B列に国が入る。末尾に ＯＥＣＤ諸国・ＡＳＥＡＮ・ＥＵ・
東欧ロシア等の**再掲**がある。

## ハマり所

### 1. 地域と国が別列。合計するときは重複に注意
A列＝地域、B列＝国。**国の行を足すと地域の行と二重になる**。地域別が欲しいならA列だけ、
国別が欲しいならB列だけを拾う。末尾の ＯＥＣＤ／ＡＳＥＡＮ／ＥＵ／東欧・ロシア等は
**再掲**なので、地域の合計に足してはいけない。

### 2. 地域区分が教材の言い方と違う
財務省は **北米 / 中南米 / 大洋州 / 中東 / アフリカ / 欧州 / アジア**。
共通テストの図でよくある「北アメリカ / 中央・南アメリカ」とほぼ対応するが、
**メキシコは財務省では「中南米」**。原問の図がメキシコをどちらに入れているか確認すること。

### 3. ヘッダーが4行＋業種が2段
1〜4行目が表題（和英）、6〜10行目が業種のヘッダー（和英2段＋折り返し）。
`header=None` で読んで11行目以降を本体として扱う。

### 4. 値が「.」や「-」のことがある
報告件数が3件に満たない場合は秘匿されて `.`。float 変換前に弾く。
（例: 2025年末の「国際機関」は `.`）

### 5. 単位は百万円
表題の近くに書かれる。ドル建てが要るなら為替は別途（World Bank `PA.NUS.FCRF`）。
