# mof / direct_investment

## 何をする

財務省が公表する **直接投資残高（地域別・業種別）** から、日本の対外／対内直接投資残高を
地域別・国別に取る。認証不要。**業種別の列（3列目以降）は `fetch.py` では取らない**（秘匿「Ⅹ」が多い。2025年末の対内で379セル）。
★この表は**親子関係原則**（関連会社から親会社への投資を回収として差し引く）で作られ、「対外資産負債残高」の直接投資（資産負債原則）とは一致しない（表の注4）。

## 取得

```
2019〜2023年  https://www.mof.go.jp/policy/international_policy/reference/iip/dip<年>.xlsx
2024年以降    https://www.mof.go.jp/policy/international_policy/reference/iip/data/dip<年>.xlsx
```
**★2024年からURLに `data/` が挟まる。** 掲載ページ（`.../iip/data/index.htm`）から拾うのが安全。
2026-10-26 の確認: 2023年は `data/` 付きが404・無しが200、2024年は両方200（**大きさが違う**＝46,960B と 46,845B。`fetch.py` は `data/` を先に取る）、2018年は両方404。
`fetch.py` は落としたファイル・保管庫のファイルとも、**表題の「対外/対内直接投資残高」「<年>年末」「単位：億円」を読んで確かめる**（大きさでは別年・エラーページを見分けられない）。

```bash
python fetch.py --years 2019-2025                     # 対外・地域別の時系列
python fetch.py --years 2025 --direction inward       # 対内
python fetch.py --years 2025 --level country          # 国別
```

## シートの構成

| シート | 中身 |
|---|---|
| `1` | **対外**直接投資残高（Outward） |
| `2` | **対内**直接投資残高（Inward） |

行は「合計 → アジア → （中華人民共和国・香港…）→ 北米 →（アメリカ合衆国・カナダ）→ …」と
**地域の下に国がぶら下がる**。A列に地域、B列に国が入る。末尾に ＯＥＣＤ諸国・ＡＳＥＡＮ・ＥＵ・
東欧ロシア等の**再掲**がある。

## ハマり所

### 1. 地域と国が別列。合計するときは重複に注意
A列＝地域、B列＝国。**国の行を足すと地域の行と二重になる**。地域別が欲しいならA列だけ、
国別が欲しいならB列だけを拾う。末尾の ＯＥＣＤ／ＡＳＥＡＮ／ＥＵ／東欧・ロシア等は
**再掲**なので、地域の合計に足してはいけない。A列にはほかに「国際機関」がある（2019〜2025年末は値が「.」）。
★**7地域の計は「合計」とわずかに合わない**（2025年末: 対外 5億円・対内 38億円 足りない）。`fetch.py` は割合の分母をシートの「合計」にし、
差を「（地域の内訳に入らない分）」の行として出す。A列に知らない区分が出たら止まる（区分名の変更を黙って通さない）。
★**国別は表に掲載のある国だけ**（対外33か国・対内32か国）。全ての国ではない。metadata の `scope` にそう出る。

### 2. 地域区分がよく使われる分け方と違う
財務省は **北米 / 中南米 / 大洋州 / 中東 / アフリカ / 欧州 / アジア**（2019〜2025年末の全シートで同じ名前）。
「北アメリカ / 中央・南アメリカ」の分け方とほぼ対応するが、
**メキシコは財務省では「中南米」**（2019〜2025年末の対外・対内とも）。比べる図がメキシコをどちらに入れているか確認すること。

### 3. ヘッダーが4行＋業種が2段
1〜4行目が表題（和英）、6〜10行目が業種のヘッダー（和英2段＋折り返し）。
`header=None` で読み、**A列の「合計」の行から**を本体として扱う（2019〜2025年末は0始まりで11行目）。

### 4. 値が「.」や「Ⅹ」のことがある
表の注による: **「.」＝該当データが存在しない**、**「Ⅹ」＝報告件数が3件に満たない（秘匿）**。float 変換前に弾く。
（例: 2025年末の「国際機関」「イラン」は `.`。「合計」の列に「Ⅹ」は無く、業種の列に多い）
`fetch.py` は落とした行の名前と記号を metadata の `verification.dropped` に残す。

### 5. 単位は億円
表題に「（単位：億円）」とある（2019〜2025年末の全シート）。**百万円ではない**（以前の版の本レシピと fetch.py は百万円と書いていた）。
CSV の列名は `value_100m_jpy`。ドル建てが要るなら為替は別途（World Bank `PA.NUS.FCRF`）。
