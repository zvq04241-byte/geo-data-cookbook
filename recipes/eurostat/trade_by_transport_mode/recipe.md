# eurostat / trade_by_transport_mode

## 何をする

「フランスとポルトガルの EU 域外への輸送手段別割合」（2023年本試Ｂ第2問）のような、
**貿易を海上・航空・道路に分けた図**を作る。輸出**額**と輸出**量**で構成比が大きく違うのが
この型の要で、額では航空が大きく、量では海上がほとんどを占める。

## ★dissemination API には無い

```
https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/DS-059331
  → 404 ERR_NOT_FOUND_4
```

TOC を `mode of transport` で引いても、出てくるのは旅行・生活時間の表ばかりで貿易は無い。
**Bulk Download の comext ツリーにある。**

```
https://ec.europa.eu/eurostat/api/dissemination/files?dir=comext
  comext/COMEXT_DATA/TRANSPORT_HS      … HS品目分類。2002年〜、319本
  comext/COMEXT_DATA/TRANSPORT_NST07   … NST2007（輸送統計の分類）
  comext/COMEXT_DATA/PRODUCTS          … 輸送手段の無い通常の貿易
```

ファイル名は `trhs_v2_YYYYMM.7z`。**`MM` が `52` のものが年計**（`trhs_v2_202552.7z` = 2025年計）。
1本48MB、展開して `trhs_202552.dat` が248MB・613万行。

## 列

```
REPORTER,PARTNER,PRODUCT,FLOW,TRANSPORT_MODE,PERIOD,VALUE_EUR,VALUE_NAC,QUANTITY_KG
FR,US,TOTAL,2,1,202552,...
```

- `FLOW` … 1=輸入 / **2=輸出**
- `TRANSPORT_MODE` … 1=海上 2=鉄道 3=道路 4=航空 5=郵便 7=固定施設 8=内陸水路 9=自走 0=その他
- `PRODUCT` … HSコード、または **`TOTAL`（全品目の合計行）**
- `QUANTITY_KG` … 重量。空のことがある（航空で約10%）

## 使い方

```bash
python fetch.py --year 2025 --reporters FR,PT --flow export --scope extra
python fetch.py --year 2025 --reporters FR,PT --scope extra --exclude-partner GB  # 新しい年を旧定義に
python fetch.py --list-years          # 2002〜2025 の24年
```

## 検証済み（2025年・EU域外への輸出・PRODUCT=TOTAL のみ）

| | 海上 | 航空 | 道路 | その他 |
|---|---:|---:|---:|---:|
| フランス 額 | 34.6% | 31.0% | 21.9% | 12.5% |
| フランス 量 | 69.0% | 0.8% | 24.7% | 5.5% |
| ポルトガル 額 | 63.5% | 17.5% | 18.7% | 0.2% |
| ポルトガル 量 | 94.2% | 0.4% | 5.4% | 0.1% |

**額と量で航空の比率が桁違い**（仏 31.0% 対 0.8%）。これがこの型の設問の決め手になる。

## 原問（2019年）の再現 ― 4つの円すべてが合う

2023年本試Ｂ第2問の図5（2019年）を再現した。**図の円は目分量で読まず、画素を数えて測った**
（凡例の4つの見本で閾値を較正。海上は平均0.58、その他は0.98、航空と道路は平均が
0.82対0.80でほぼ同じなので、半径2でぼかしたときの標準偏差 0.16対0.10 で分ける）。

| | 図を測った値 | 本レシピの実測 | |
|---|---|---|---|
| ① | 海上80.7 / 航空5.0 / 道路12.4 / 他1.9 | 75.7 / 1.0 / 18.3 / 5.0 | **フランス・輸出量** |
| ② | 海上95.8 / 航空4.2 / 道路0 | 92.3 / 5.8 / 1.9 | **ポルトガル・輸出量** |
| ③ | 海上46.3 / 航空31.7 / 道路9.5 / 他12.5 | 37.0 / 34.2 / 13.7 / 14.9 | **フランス・輸出額** |
| ④ | 海上77.4 / 航空16.9 / 道路5.7 | 73.6 / 19.0 / 7.1 | **ポルトガル・輸出額** |

ア＝フランス、イ＝ポルトガル、**E＝輸出量、F＝輸出額**。正解の「フランスの輸出額」は③。
域外輸出総額もフランス213十億EUR・ポルトガル13.9十億EUR で公表実額と合う。

★はじめ目分量で「ポルトガルが合わない」と判断したが、**読み違いだった**。
円グラフは面積の見当が当てにならない。測ること。

## 2019年から2025年への変化 ― ポルトガルの道路が2.5倍

| ポルトガル・域外輸出額 | 海上 | 航空 | 道路 |
|---|---:|---:|---:|
| 2019年 | 75.3% | 16.8% | 7.5% |
| 2025年 | 63.5% | 17.5% | **18.7%** |

道路の内訳を相手国別に見ると理由がはっきりする。

| 相手 | 2019年 道路額 | 2025年 道路額 | |
|---|---:|---:|---|
| イギリス | ―（当時は域内） | 16.2億EUR（道路の41.5%） | **離脱で域外に入った** |
| スイス | 4.9億 | 7.2億 | もともと陸路 |
| モロッコ | 1.0億 | 4.9億 | **5倍**。スペイン経由の陸送 |
| ウクライナ | ―（少額） | 1.8億（うち道路95.0%） | **海路が戦争で塞がり陸送へ** |

## ハマり所

1. **dissemination API を引いて404を見ても「無い」ではない。**
   `DS-059331` は404を返すが、Bulk Download には在る。API と バルクは別系統。
2. **★品目別の行と `PRODUCT=TOTAL` の合計行が同居している。全部足すと二重計上。**
   これを踏むとポルトガルの航空輸送が重量の9.9%（235万トン）になる。
   リスボン空港の年間貨物取扱量は15万トン程度なので、数字を見れば気づける。
   **`PRODUCT == "TOTAL"` だけを使う**か、`!= "TOTAL"` だけを使う。
3. **相手国コード `QS` は「船舶・航空機への積込み」**（bunkers and stores）。
   ジェット燃料が `TRANSPORT_MODE=4`（航空）で計上され、航空貨物に紛れ込む。
   `Q` で始まる特殊コード（QR/QS/QU/QV/QW/QX/QY/QZ）は国ではない。除く。
4. **域内／域外は列に無い。相手国が EU27 かどうかで自分で分ける。**
   ★**英国は2021年から域外**。過去問に「EUにはイギリスを含む」と注記があれば、
   その年の定義に合わせて `GB` を除く。実測ではフランスの道路が
   16.2%（英=域内）→ 21.9%（英=域外）と5.7ポイント動く。
5. **`.7z` である。** `zipfile` では開けない。`py7zr`（`pip install py7zr`）を使う。
   macOS に `7z` コマンドは既定で入っていない。
6. **`QUANTITY_KG` は空のことがある。** 航空で約10%、郵便で約50%。
   重量の構成比を出すときは、欠測が多い手段で過小になる。
7. **`TRANSPORT_HS` は域外貿易のみ。** `--scope intra` は0件になる。
   域内の輸送手段別は `TRANSPORT_NST07` 側（ディレクトリの注意書きに
   「new format for intra-EU trade by mode of transport by NST2007」とある）。
8. **Comext はその年のEU定義を使う。** 英国は2019年のファイルに**1行も出てこない**
   （当時は域内）。2025年には38.2十億EURで現れる。
   **古い年はそのまま引けばよい。** `--exclude-partner GB` が要るのは、
   新しい年を旧定義に合わせて比べるときだけ。
9. **円グラフを目分量で読まない。** 本レシピの検証で、はじめ目分量で読んで
   「ポルトガルが合わない」と誤判断した。凡例の見本で閾値を較正し、角度ごとに
   画素を分類して数えると4つとも合った。**扇形の面積は当てにならない。**
10. **国によって現れる輸送手段が違う。** ポルトガルには 7=固定施設 と 8=内陸水路 が無い
   （パイプラインも国際河川も無いので当然）。「手段が7種しかない＝データ不良」ではない。
   なお `COMEXT_DATA` 直下に「missing extra-EU data for Greece / the Netherlands」
   という注意書きがあり、**国ごとの欠測は実在する**。読む前に見る。
