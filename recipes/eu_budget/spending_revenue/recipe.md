# eu_budget / spending_revenue（EU予算 加盟国別の受取額・支払額）

## 何をする
欧州委員会が毎年公表する「EU spending and revenue」の xlsx（2000年〜の年ごとのシート）から、
加盟国ごとの **受取額**（EU予算からその国への支出）と **支払額**（その国がEU予算に払った自己財源）を取り、
CSV（受取・支払・差引）と metadata.json を出す。純拠出国／純受取国の棒グラフの元データになる。

```bash
python fetch.py                                          # 2024年・全加盟国（xlsx は配布ページから落とす）
python fetch.py --year 2024 --countries DE,PL,NL,LU      # 国を絞る（ISO2）
python fetch.py --year 2024 --with-ngeu                  # 受取額に NextGenerationEU を足す
python fetch.py --year 2014 --payments national_contribution
python fetch.py --xlsx raw/xxx.xlsx --list-years         # 手元の xlsx を使う
```
配布ページ: https://commission.europa.eu/strategy-and-policy/eu-budget/long-term-eu-budget/2021-2027/spending-and-revenue_en
（xlsx の文書IDは版ごとに変わるので、`fetch.py` はページからリンクを探して落とす）

## なぜこのレシピがあるか
国名をカタカナ順に並べた表から値を拾うと、隣の国（ルーマニアとルクセンブルクなど）の値を取り違えやすい。
加盟国ごとの値を ISO2 で一意に取るために作った。最初に当てたとき支払額が全部空になったのは、
**「TOTAL REVENUE」の行には国別の値が入っていない**ためで、国別の支払額は「TOTAL own resources」の行にある。

```
2024年（百万ユーロ）    受取      支払      差引
  ドイツ             12,619.8  31,381.2  −18,761.4
  オランダ            3,152.7   8,097.1   −4,944.4   ← 関税で支払額が膨らむ（下の罠6）
  ハンガリー          3,452.9   1,767.8   +1,685.1
  ポーランド          9,147.8   7,421.3   +1,726.5
  ルクセンブルク      2,811.6     409.5   +2,402.1   ← 豊かな国なのに純受取（下の罠5）
検算: 加盟国の合計 = EU-27 の列（受取 122,957.1・支払 141,045.4）
```

## ハマり所

1. **支払額は「TOTAL own resources」**。「TOTAL REVENUE」には国別の値が無く、空を0と読むと全部の国が0になる
2. **シートの作りが年で違う**（見出し行・ラベルの列・EU集計の列）。位置を決め打ちせず名前で探す
3. **加盟前の国にも列がある**。その年の加盟国だけを残さないと、受取額の合計がEU集計を上回る
4. **NextGenerationEU は別ブロック**。足すかどうかで順位が変わる。どちらで描いたかを注に書く
5. **ルクセンブルク・ベルギーは行政支出で受取額が膨らむ**。豊かな国でも純受取になる
6. **支払額には関税が入る**。港のある国（オランダ・ベルギー）が膨らむ
7. **国は ISO2。ギリシャは EL**、イギリスは UK

### 1. 支払額は「TOTAL own resources」。「TOTAL REVENUE」には国別の値が無い
REVENUE のブロックで国別に値があるのは自己財源（関税・VAT財源・GNI財源・プラスチック財源）とその合計まで。
「TOTAL REVENUE」は EU 全体の収入（借入・罰金なども含む）で、国の列は空。**空を0と読むと全部の国の支払額が0になる。**

### 2. シートの作りが年で違う → 位置を決め打ちしない
| | 2000〜2010年 | 2014・2020年 | 2024・2025年 |
|---|---|---|---|
| ラベルの列（0始まり） | 3（2000・2004年）・2（2010年） | 1 | 合計行で 0 と 1 が混在 |
| EU集計の列 | EU-15／EU-25／EU-27 | EU-28 | EU-27 |
| 支払額の行 | TOTAL own resources（＋national contribution） | 同左 | TOTAL **O**wn resources（大文字） |
`fetch.py` は、国コードが最も多く並ぶ行を見出しとし、合計行は先頭6列から**大文字小文字を無視して名前で**探す。

### 3. 加盟前の国にも列がある → その年の加盟国だけを残す
2010年以前のシートには、まだ加盟していないブルガリア・ルーマニア・クロアチアなどの列があり、加盟前支援の受取が入る。
これを足すと受取額の合計が EU集計の列を上回る（2000年で 77,476.0 ≠ EU-15 76,462.9）。
加盟年（2004年10か国・2007年 BG/RO・2013年 HR）とイギリスの離脱（2020年まで列あり）で絞る。
**検算: 加盟国の合計 ＝ EU集計の列**（受取・支払とも）。2000・2004・2007・2010・2013・2020・2024年で一致を確認。

### 4. NextGenerationEU（復興基金）は別ブロック
2021年以降、「TOTAL EXPENDITURE」には NGEU（復興・強靭化ファシリティ等）の支出が入っていない。別の表「TOTAL NGEU」。
足すかどうかで国の順位が変わる（2024年 ドイツの受取 12,620 → NGEU込み 27,842）。
**図に使うときは、どちらで描いたかを出典の注に書く**（`--with-ngeu`）。

### 5. ルクセンブルク・ベルギーは行政支出で受取額が膨らむ
EU の機関が置かれているので、職員給与などの行政支出がその国の「受取」に計上される。
ルクセンブルクは豊かな国なのに純受取になる。**「豊かな国＝純拠出」の判定の足場には使えない。**

### 6. 支払額には関税が入る（港のある国が膨らむ）
自己財源のうち関税（伝統的自己財源）は、輸入品が通関した国が集めて納める。ロッテルダムのオランダ、アントワープのベルギーは、
自国の経済規模以上に支払額が大きく出る。GNIに応じた負担だけを見たいときは「Own resources based on GNI」の行を使う。
2020年までのシートにある「TOTAL national contribution」は関税を除いた国民拠出金（`--payments national_contribution`）。

### 7. 国は ISO2。ギリシャは EL
GR ではなく **EL**。イギリスは UK（GB ではない）。`NAMES` 辞書でカタカナにする。

## 効くケース
- 純拠出国・純受取国の棒グラフ（「支払額と受取額のいずれか」を問う図）。
- 東ヨーロッパ諸国の受取超過、拠出国の不公平感の背景説明。

## 効かない／別レシピ
| 要求 | 対応 |
|---|---|
| 分野別（農業・結束政策）の受取額 | 同じシートの上の行（3.1.11 EAGF、2.1.11 ERDF など）。`parse()` の ROWS に足す |
| 1人当たり・GNI比 | 人口は un_wpp、GNI は同シート下部の「Gross National Income」行 |
| 2025年 | シートはあるが、公表の時期によっては計画値の場合がある。使う前に配布ページの説明を確かめる |
