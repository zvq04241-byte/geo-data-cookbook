# jnto / inbound_outbound

## 何をする
日本政府観光局(JNTO)の公開PDF「年別 訪日外客数、出国日本人数の推移」から、**1964年〜最新年**の
2系列を取得しCSV化する。観光（インバウンド/アウトバウンド）の長期推移グラフ・正誤設問に使う。

## API情報 / 使い方
- 出典: JNTO 統計（無認証・公開PDF）。`https://www.jnto.go.jp/statistics/data/` の
  「年別 訪日外客数、出国日本人数の推移」リンク先PDF。
```bash
python fetch.py --output-dir ./output           # 最新URLが変わったら --url で差し替え
```
出力: `<date>_jnto_inbound_outbound.csv`（year, visitor_arrivals, japanese_overseas, 単位＝人）＋ metadata.json ＋ 読み取り元の PDF（`<date>_jnto_inbound_outbound_source.pdf`、sha256 を metadata に）。
`fetch.py` は、見出しに単位「人」「persons」が無い・ある年のカンマ付きの数が2つでない・1964年から最終年までに欠けた年がある、のどれかで止まる。

参照値（人）: 2026-10-26 に `DEFAULT_URL` の PDF（20250820_1615-8.pdf、1964〜2024年の61年）を `fetch.py` で読んだ値。
| year | 訪日 | 出国 | 大小 |
|---|---|---|---|
| 1964 | 352,832 | 127,749 | 訪日>出国 |
| 1970 | 854,419 | 663,467 | 訪日>出国 |
| 1971 | 660,715 | 961,135 | **出国>訪日へ逆転** |
| 2014 | 13,413,467 | 16,903,388 | 出国>訪日 |
| 2015 | 19,737,409 | 16,213,789 | **訪日>出国へ再逆転** |
| 2019 | 31,882,049 | 20,080,669 | 訪日>出国 |
| 2021 | 245,862 | 512,244 | **出国>訪日**（コロナ期） |
| 2022 | 3,832,110 | 2,771,770 | **訪日>出国** |
| 2024 | 36,870,148 | 13,007,282 | 訪日>出国（訪日は2019年を上回り、出国は2019年を下回る） |
大小が入れ替わった年は 1971・2015・2021・2022 の4回（同数の年は無い）。

## ハマり所
1. **二次資料は収録期間が短いことがある。長期（1964〜）はJNTO原典PDFを直接**取る（PDFの最初の年は1964年）。
   1985年以降の出国の急増（1985年 494.8万人→1987年 682.9万人）、1971/2015の逆転、コロナ前後の回復差は、この1本で描ける。
   出国の急増の背景（円高など）は、この表からは言えない。書くなら別の資料で確かめる。
2. **PDFパース**: 各年ブロックは「年・和暦・訪日(カンマ区切り数)・伸率・出国(カンマ区切り数)・伸率」。
   **伸率（15.5 / △22.7）はカンマ無し → カンマを含む数だけが訪日・出国**。これで読み飛ばし判定する。
3. **年次更新でPDFファイル名（URL）が変わる**。`DEFAULT_URL` は固定なので、404時は統計ページで最新リンクを確認。
4. **コロナ後の回復は非対称**: 訪日は2024年に2019年を上回り（3,687万人＞3,188万人）、出国は下回る（1,301万人＜2,008万人）。
   ★コロナ期の2021・2022年にも大小が入れ替わる。「逆転は1971年と2015年」とだけ書くと誤りになる。

## 効くケース
- 観光の長期推移（折れ線2本）、訪日↔出国の逆転、円高/ビザ緩和/LCC/オーバーツーリズム/コロナの正誤設問。
- 図はインバウンド急増で近年が巨大 → 直線目盛りだと古い年が潰れる。**起点を1980年代にする**と出国増が見える
  。

## 規約準拠
- `Path(__file__)` 基点、`encoding="utf-8"`、`newline="\n"`、`DataFetchError`、User-Agent付与、
  metadata.json（source/url/sha256/scope/source_pdf/retrieved_at）、パース異常時は単位・各年の個数・欠けた年で fail。
