# figure / flow_map

## 何をする

`lib/world_map.py` の基本図の上に、起点→相手国の流れを帯で描く。
**実装は `_workspace/scripts/lib/flow_map.py` にある。読むより呼ぶこと。**

```python
from lib.world_map import load_base, draw_base
from lib.flow_map import draw_flows, check_reach, classify, deg_per_pt, DOT_Z, NAME_Z

base = load_base(BBOX, scale="110m")
draw_base(ax, base, facecolor="0.955", edgecolor="0.55",
          lw_coast=0.35, lw_border=0.35, lw_disputed=0.35)
dpp = deg_per_pt(BBOX, fig_w_in=13.2, ax_w_frac=0.976)
draw_flows(ax, origins, flows, widths=WIDTH, spread=SPREAD, dpp=dpp)
ax.plot(x, y, "o", zorder=DOT_Z)          # ★注記は必ず流線より上
bad = check_reach(png, ax_rect, BBOX, flows, origins, widths=WIDTH)
assert not bad
```

`origins` = `{名: (lon, lat, 階調, 弧の基準)}`／`flows` = `[{origin, name, lon, lat, k}]`

## まず決める ― この図は「実際の経路」か「雰囲気」か

流線図には2種類ある。**どちらを作るのかを先に決め、図にそう書く。**

| | 実際の経路を描く | 雰囲気を示す（**ふつうはこちら**） |
|---|---|---|
| 線が意味するもの | 航路・便・パイプラインの通り道 | 向きと量だけ |
| 地点の座標 | **出所の要る実測値**（港・空港） | **置き場所**。模式であって測定値ではない |
| 線の形 | 大圏・実航路・実在の管路 | 読みやすさで決めてよい |
| 重なり | 実態なので動かせない | **設計の対象**。ずらしてよい |
| 注記 | 経路の出所を書く | 「弧は向きのみを示し、航路ではない」と書く |

**流線は重なるのが普通である。** 重なりは不具合ではなく、**デザインで解くもの**。
消し切ろうとしない。下の4つは「重なりを無くす」ためではなく、
**重なったときに何を読み取れるようにするか**を決める道具である。

読み取れるようにする優先順位（迷ったらこの順）:

1. どの起点から出ているか（階調）
2. いちばん太い流れの大きさ（階級と凡例）
3. 相手国がどこか（点と地名）
4. 個々の帯の経路の全体 ← **これは最後。捨ててよい**

★座標を `PLACE` に手で書くときは、**模式か実測かをメタデータに明記する。**
模式なら「置き場所」と書く。書かずに置くと、後から実測値として読まれる。
（図の地点座標を目分量で打ち、3校まで通した事例がある。）

## 規約（どれも実際に踏んでから決めた）

### 1. 線幅は階級。値に比例させない
鉄鉱石2024は 中国 69.3 対 オランダ 0.01 で**7000倍**。比例させると細い線が消える。

### 2. 階級の上限は「最大値が単独で入る」ところに置く
上限を10にしたら、豪州→中国 69.3 と ブラジル→中国 19.9 が**同じ太さ**になり、
3.5倍の差が消えた。30 で1段足して解決。

### 3. 矢じりは帯の幅に比例させる（流線図の作法）
ただし **`FancyArrowPatch` 1本では、矢じりが大きいほど先端が目標より手前に落ちる**。
実測: `mutation_scale=27.9` で **5.2度**。`shrinkB` を負にしても縮むだけ。
→ **線と矢じりを分け、三角形を自分で置く。** 比例と到達が両立する。

### 4. 重なりは「消す」のではなく「設計する」。道具は4つ
| | 何が起きるか |
|---|---|
| 方位の順に弧を**扇状**に開く | 同じ方角へ出る束がばらける |
| **透過**（0.78） | 交わったところで下の帯が見える |
| **極細の白縁**（片側0.6pt） | これが無いと帯どうしの**境目が溶けて1本に見える** |
| 重ね順は**細いほど上** | 台湾(2pt)が中国(18pt)の下に完全に隠れた |

**量の大小と、見える・見えないを一致させない。**

4つを全部使っても重なりは残る。**残ってよい。** 上の優先順位1〜3が読めていれば足りる。

### 5. 同じ点に2本来るときは、細いほうが手前で止まる
太い帯が細い側の矢じりを覆う（中国で画素0になった）。
★最初は「後から描く起点が必ず譲る」と決め打ちしたが、マレーシアとオランダでは
**譲るべき側が逆**だった。幅で決める。

### 6. 注記は必ず流線より上に置く
1本ごとに重ね順を振ると z が大きくなる（20本で44）。白縁が**地名を覆った**。
`DOT_Z=60 / NAME_Z=62 / ORIGIN_Z=64 / LEGEND_Z=70`。`draw_flows` が assert で見張る。

### 7. 目視で「届いている」と決めない
`check_reach()` で画素を数える。**相手国のラベル文字を拾わない**よう、
起点ごとの色（α合成後の階調）で測る。単に「濃い画素があるか」では通ってしまう。

### 8. 図の中心は「流れの向きが実態と合う」ように選ぶ
鉄鉱石はブラジル→東アジアが主なので**0度中心**。大西洋・アフリカ南・インド洋を通り、
喜望峰まわりの実際の向きと一致する。太平洋中心だと同じ流れが西回りに見える。

### 9. 流線が1本も通らない範囲は切る
鉄鉱石では太平洋〜北米西岸が空で、図が痩せていた。西経95度で切って2割大きくなった。

## 注記に必ず書くこと

```
弧は輸出の向きのみを示し、航路ではない。
（相手国名に "Other Asia, nes" が出たら）「台湾」は原表記 Other Asia, nes。
```
