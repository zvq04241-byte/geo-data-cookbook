# e-Stat / manufacturing_shipment_prefecture（製造業 都道府県別 産業中分類別）

## 何をする
製造業の **製造品出荷額等**（や付加価値額・事業所数等）を **都道府県別 × 産業中分類別** に取得し、
上位ランキング CSV + metadata.json を出力する。食料品に限らず任意の中分類で使える。

```bash
export ESTAT_APP_ID=...                                  # .env にあり
python fetch.py --list-industries                        # 取得可能な中分類・実績年を列挙
python fetch.py --industry 食料品製造業 --measure 出荷額 --top-n 12             # 都道府県(既定)
python fetch.py --level municipality --industry 食料品製造業 --top-n 20         # 全市区町村
python fetch.py --industry 輸送用機械 --measure 出荷額 --year 2023 --output-dir ./out
```
`--level prefecture`（既定・都道府県+政令市）/ `--level municipality`（全1,946地域・町村含む）。

## ★なぜキーワード検索で見つからないか（このレシピの存在理由）
「製造品出荷額等・都道府県別・最新年」で検索しても**一発で当たらない**。理由:
1. **「製造品出荷額等」はヒットしすぎる** — 工業統計（〜2020・廃止）＋経済センサス活動調査（2012/16/21）＋
   経済構造実態調査（2019〜）の3系統15年分が同語でヒット。検索は「どれが現役か」を順位づけできない。
2. **正解表のタイトルに「都道府県別」が無い** — 当たりは「**地域編** 産業中分類別…製造品出荷額等」。
   都道府県は*データの軸*でタイトル語でない。「都道府県別」で強く出るのは用地用水編(30人以上)や概要(順位表)など別物。
3. **「最新年」は検索概念にならない** — e-Statは新旧を区別しない。さらに最新表の中に複数実績年が同居し、
   **調査年≠実績年**（2024年*調査*＝2023年*実績*）。年は表を開いて cat02 から選ぶしかない。
→ 検索が出すのは候補まで。**どの調査系統か（制度の系譜）＋メタ確認＋数値検算**が人/レシピの担当。

## 現役の系統（重要なドメイン知識）
- **工業統計調査は廃止**（最終2020年調査）。後継は **経済構造実態調査（毎年）** ＋ **経済センサス活動調査（5年ごと）**。
- 都道府県×産業中分類×出荷額は、経済構造実態調査の **製造業・地域編**「産業中分類別…製造品出荷額等」表。

## 表ID（地理レベル・調査年で変わる・更新必須）
| レベル | 調査年(=実績年) | statsDataId | 地域粒度 | 出荷額cat01 / 単位 / cat02並び |
|---|---|---|---|---|
| 都道府県 | 2024(2023) | `0004035171` | 全国+47+政令市20+特別区 = 69 | `000004010050` / 百万円 / 年_産業_地域 |
| **市区町村** | 2024(2023) | **`0004035178`** | 全国+都道府県+全市区町村 = 1,946（町村含む） | `000004080070` / **万円** / **年_地域_産業** |

### ★★ 罠: 地理レベルで「別の表」＋タイトルでは見分けられない
`0004035171` と `0004035178` は **タイトルがほぼ同名**（どちらも「地域編 産業中分類別…製造品出荷額等…（全事業所）」、
末尾が「付加価値額」か「粗付加価値額」かの差だけ）。違うのは**地域粒度**で、しかも
**①statsDataId ②指標cat01コード(010050↔080070) ③単位(百万円↔万円) ④cat02の並び順(産業_地域↔地域_産業)** が全部違う。
- **見分け方＝市区町村名で検索する**: `getStatsList searchWord="経済構造実態調査 岡崎市 製造品出荷額"` を打つと、
  岡崎市を含む（=市区町村まで持つ）表 `0004035178` が当たる。**タイトル検索では永遠に見つからない**（全1,016表に「市区町村」の語なし）。

**次年の表IDの探し方**: `getStatsList searchWord="経済構造実態調査 <市区町村名> 製造品出荷額"`（市区町村）/
`"経済構造実態調査 製造業"`（都道府県）→ SURVEY_DATE 最新の `@id`。タイトルが同名なので area軸の規模(getMetaInfo)で都道府県(69)か市区町村(1946)かを確認。

## ハマり所（重要）

### 1. 指標は cat01。**cdTab でなく cdCat01 で絞る**（最重要）
表章項目（事業所数/従業者数/人件費/原材料/**製造品出荷額等**/付加価値額の6種）は cat01。
`cdTab=...` を渡しても**黙って無視され6項目すべて返る**（@tab=None）。→ 値が混在し桁が狂う。
必ず `cdCat01=000004010050`（製造品出荷額等）で絞ること。コードは MEASURES 辞書参照。

### 2. 都道府県は複合 cat02 に埋没＋政令市が混在
cat02 は「時間軸_産業分類_地域」の**複合分類**（例 `2023000000_2023_09_食料品製造業_13_東京都`）。
同じ表に**政令指定都市・特別区**（5桁コード: 札幌市=01100 等）も入る。
→ 都道府県だけにするには **地域コードが2桁(01-47)** のものに限定（`PREF2` 正規表現）。市を入れると47が141件等に膨れ順位が汚れる。

### 3. 調査年 ≠ 実績年／複数年同居
2024年*調査*の表に2021/2022/2023*実績*が同居。`--year` で実績年を選ぶ（既定=最新実績年）。

### 4. limit のサイレント打切り
既定 limit は小さい。cat02×cat01 の総数は1万超。`cdCat01` で絞れば約1765件に収まる。
RESULT_INF.TOTAL_NUMBER で打切りを検知している。

### 5. 検算: 47都道府県合計 == 全国計
全国計（地域コード `00_全国計`）と47県合計が一致するか必ず照合。
一致しなければ抽出条件（年・中分類名・市の混入）を疑う。metadata の `verification_47sum_equals_national`。

### 6. 中分類名の表記ゆれ
`--industry` は部分一致（「輸送用機械」→「輸送用機械器具製造業」、「化学」→「化学工業」）。
正式名は `--list-industries` で確認。

### 7. 市区町村レベル特有（--level municipality）
- **単位が万円**（都道府県表は百万円）→ 億円換算の除数が違う（万円/10000, 百万円/100）。
- **政令市は「市計」と「区」が併存** → 政令市の区（`○○市△区`＝名前に「市」を含む）を除外し市計を採用。**東京は個別の23特別区を採用**（"特別区部"の集計行を除外。"中央区"等は名前に「市」が無いので残る）。各行が一意の基礎自治体になる。
- **小規模自治体は秘匿(X)/欠損** → 数値化できず除外（metadata の suppressed_or_missing に件数）。
- そのため **市区町村は「47=全国」型の検算が成立しない**（区除外＋秘匿）。件数と全国計の併記で妥当性を見る。

## 効くケース
- 「○○（業種）の製造品出荷額、都道府県トップN、最新年」型の教材データ（階級区分図・棒グラフ）。
- 出荷額以外（付加価値額・事業所数・従業者数）も `--measure` で同型取得。

## 効かない/別レシピ
| 要求 | 対応 |
|---|---|
| 市区町村別 | 別表（市区町村編）が要る。本レシピは都道府県のみ |

| 時系列（長期） | 工業統計の旧表と接続が必要（定義・調査変更に注意）。別レシピ候補 |
| 飲料・たばこ・飼料 | 中分類10。`--industry 飲料` 等で取得可（食料品09とは別） |

## このレシピを使うLLMへのヒント
1. **製造業の県別統計は『経済構造実態調査・地域編』が現役**。工業統計/旧センサスに引っ張られない。
2. **表章項目は cdCat01 で絞る**（cdTab は効かない）。これはこの統計群共通の罠。
3. **複合分類(年_産業_地域)＋政令市混在** → 地域コード2桁で都道府県を切り出す。
4. **47県合計＝全国計**で必ず検算してから数値を出す。
5. 表IDは毎年変わる → getStatsList で最新 SURVEY_DATE を引いて更新。
