# e-Stat / population_natural_change_prefecture（人口推計 都道府県別 自然増減率）

## 何をする
人口推計の **都道府県別自然増減率** を取り、47都道府県のランキング CSV か、1県の全期間の推移 CSV を、metadata.json とともに出す。

```bash
export ESTAT_APP_ID=...                      # .env にあり
python fetch.py --list-periods               # 表にある期間を列挙
python fetch.py                              # 最新期間の47都道府県ランキング
python fetch.py --period 2021                # 2021年10月～2022年9月
python fetch.py --area 沖縄県                 # 1県の全期間の推移
```

## なぜこのレシピがあるか
「沖縄県は自然増加率がプラスの県」という説明を、このレシピで当てると、沖縄県は **2021年10月～22年9月に −0.5‰ でマイナスに転じ**、2023年10月～24年9月は −2.3‰。
同じ期間は **47都道府県すべてがマイナス**で、沖縄県は減少幅が最も小さい（1位）。
**「沖縄＝自然増」は数年前までの常識で、今は成り立たない。** 説明文が古い常識のままになっていないかを当てるのに使う。

```
沖縄県  2016-17 +2.9 / 2017-18 +2.6 / 2018-19 +2.0 / 2019-20 +1.9 / 2020-21 +0.9
        2021-22 −0.5 / 2022-23 −1.4 / 2023-24 −2.3   （‰）
2023-24 上位  沖縄 −2.3 / 東京 −3.7 / 滋賀 −4.4    下位  岩手 −12.7 / 青森 −13.0 / 秋田 −15.6   全国 −7.2
```
（2026-10-24 に fetch.py で取得した値。出力の CSV と metadata を `references/` に置いた。記録は `references/verify_2023_24.md`）

## ハマり所

1. **期間は暦年でなく前年10月～当年9月**。「2024年」と書くと人口動態統計の暦年の値と取り違える
2. **人口動態統計（厚生労働省）とは別の数字**。対象（外国人を含むか）も期間も違う。照合先がどちらかを先に確かめる
3. **単位は‰**（人口千人当たり）。％ではない
4. **表は国勢調査の基準ごとに別**。基準が違うと同じ期間でも値が違う。長期の系列は補間補正人口の表で
5. **検算は「47都道府県と全国がそろうか」だけ**。率なので合計の検算はできない

### 1. 期間は暦年ではない（前年10月～当年9月）
人口推計は「各年10月1日現在」の人口を基準にしているので、増減は **前年10月1日～当年9月30日** の1年間。
時間軸のコード `2023001011` は「2023年10月～2024年9月」。**「2024年の自然増減率」と書くと、暦年の人口動態統計と取り違える。**
教材に書くときは「2023年10月～24年9月」か「2024年（10月1日現在の推計）」と期間を明示する。

### 2. 人口動態統計（厚生労働省）とは別の数字
| | 人口推計（このレシピ） | 人口動態統計 |
|---|---|---|
| 期間 | 前年10月～当年9月 | 暦年（1月～12月） |
| 対象 | 総人口（外国人を含む） | 日本における日本人（概数・確定数で表が別） |
| 指標 | 自然増減率（‰） | 出生数・死亡数・自然増減数 |

同じ「自然増減」でも値が一致しない。**照合するときは、照合先の資料がどちらの統計かを先に確かめる。**

### 3. 単位は‰（人口千人当たり）
`@unit` は「千人比，‰」。％ではない。

### 4. 表は国勢調査の基準ごとに別
`0003448235` は令和2年国勢調査基準で、2016年10月～の期間を持つ。新しい年の推計が公表されると期間が1つ増える（公表の時期はこのレシピでは確かめていない）。
平成27年基準は `0003459025`、平成22年基準は `0004008047` など、**基準が違うと同じ期間でも値が違う**（補間補正）。
長期の推移を1本の系列で描くときは、国勢調査結果による補間補正人口の表（`0004021105` 等）を使う。
**次の基準の表の探し方**: `getStatsList searchWord="人口推計 都道府県 自然増減率"` → 表題「都道府県別自然増減率－総人口」で SURVEY_DATE・基準年の新しいものを選ぶ。

### 5. 検算は「そろっているか」だけ
率なので、47都道府県の合計＝全国の検算はできない（単純合計は全国の率にならない）。47都道府県のコード（01000〜47000）が過不足なくそろい、全国（`00000`）があることを確かめる（metadata の `verified`、範囲は `scope`）。
数値でない値は落として `skipped_non_numeric` に残す。期間の「最新」は時間軸コードの最大で選ぶ（返る順に頼らない）。`--area` が複数の地域に当たると止まる。

## 効くケース
- 「自然増加率が全国で最も高い県」「自然増の県はいくつあるか」を当てる。
- 1県の自然増減の転換点（プラス→マイナス）を年で示す。

## 効かない／別レシピ
| 要求 | 対応 |
|---|---|
| 出生数・死亡数そのもの | 人口動態統計（`0003411562` 上巻 都道府県別人口動態総覧 など）。暦年 |
| 社会増減率 | 同じ人口推計の「都道府県別社会増減率」表（同じ形） |
| 合計特殊出生率 | 人口動態統計。都道府県別は確定数の表 |
