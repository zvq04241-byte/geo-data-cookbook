# e-Stat / commerce_sales_prefecture（卸売業・小売業 都道府県別）

## 何をする
**年間商品販売額**（や事業所数・従業者数・売場面積）を **都道府県別 × 産業分類別** に取得し、
上位ランキング CSV + metadata.json を出力する。飲食料品に限らず任意の卸売/小売分類で使える。
姉妹レシピ: `estat/manufacturing_shipment_prefecture`（製造業側）。3指標(製造→卸→小)の比較に。

```bash
export ESTAT_APP_ID=...
python fetch.py --list-industries                       # 産業分類(コード:名称)を列挙
python fetch.py --industry 52 --measure 販売額 --top-n 12   # 飲食料品卸売業（都道府県）
python fetch.py --level municipality --industry 58 --top-n 20  # 飲食料品小売・全市区町村
python fetch.py --industry 58 --measure 売場面積   # 名称でも可（複数に当たると候補を出して止まる）
```
`--level prefecture`（既定・都道府県+政令市の表から47都道府県だけ）/ `--level municipality`（全市区町村・町村含む）。
CSV は**全件**（rank 付き）。`--top-n` は画面表示の件数だけを変える。範囲は metadata の `scope` に、除外した行の数は `excluded_counts` に書く。
`--industry` を名称で渡して複数の分類に当たったときは、候補を出して止まる（最初の1件に黙って決めない）。

## ★なぜキーワード検索で見つからないか
- **商業統計調査は2014年の調査が最後**。2016年・2021年の卸売/小売の年間商品販売額（都道府県・産業分類別）は **経済センサス活動調査** で取る。「商業統計」で探すと古い表に当たる。
- 製造業（経済構造実態調査）とは**別の調査・別の分類体系**。「食料品」も非対称:
  製造=**食料品製造業(09, 飲料を含まない)** / 商業=**飲食料品(52卸・58小, 飲料を含む)**。
- 最新の構造データは2021調査だが、**年間商品販売額の実績は2020暦年**（調査年≠実績年）。

### ★ 東京・政令市の重複排除（市区町村レベル）
市区町村表には **政令市の「市計」と「区」**、**東京の「特別区部（集計）」と個別の特別区** が併存。重複防止の統一ルール:
- **政令市＝市計を採用**（区＝"○○市△区"で名前に「市」を含む→除外）。
- **東京＝個別の23特別区を採用**（"特別区部"の集計行を除外）。"中央区"等は名前に「市」が無いので残る。
- これで各行が一意の基礎自治体になる（特別区は独立自治体、政令市の区は行政区＝市に内包）。
- 除外は**名前の規則**による。fetch.py は除外した行の数（`excluded_counts`）と、残った東京の特別区の数（`tokyo_special_wards_kept`、23でなければ警告）を metadata に書く。
- 市区町村レベルでは「47=全国」の検算が成立しない（区の除外＋秘匿）。件数・秘匿数・全国計を並べて見る。

**次census(2026予定)の表IDの探し方**:
`getStatsList searchWord="経済センサス活動調査 卸売業 小売業 産業別 年間商品販売額 都道府県"` →
「都道府県別…産業分類細分類別…年間商品販売額」で最新 SURVEY_DATE の `@id` を採用。tabコードも census 年依存（`703-<census>`）。

## ハマり所（重要）

### 1. 指標は **tab（表章項目）**。`cdTab` で絞る
製造業表(0004035171)は指標が cat01 だったが、**商業表は tab**。
`cdTab=703-2021`（年間商品販売額）。他に 701=事業所数 / 723=従業者数 / 704=売場面積。MEASURES辞書参照。

### 2. 産業は cat01（卸小売の細分類220種）
中分類はコード直接指定が楽: **52 飲食料品卸売業 / 58 飲食料品小売業**、総数は **I1 卸売業計 / I2 小売業計**。
`--list-industries` で全コード確認。

### 3. 従業者規模は cat02 → **合計=0** を指定
規模別(2人以下〜100人以上)が cat02。`cdCat02=0`（合計）にしないと規模別が重複して出る。

### 4. 都道府県は area（5桁・末尾000）＋政令市混在
area=70（全国`00000`＋47都道府県`01000`〜`47000`＋政令市`01100`等）。
**末尾000かつ先頭2桁01-47**で都道府県のみ抽出。`00000`(全国)と政令市(5桁≠末尾000)を除外。

### 5. VALUE が単一だと dict（list でない）
絞り込みで1件だけ返ると `DATA_INF.VALUE` が **dict**。`vlist()` で list 正規化（e-Stat共通罠）。

### 6. 調査年 ≠ 販売額の実績年
2021調査の**年間商品販売額は2020暦年**（コロナ初年: 外食減・内食増で小売やや上振れ）。
事業所数等は2021時点。metadata に reference_year を分けて記録。

### 7. 卸売は多段階で“水増し”（解釈の罠）
卸売販売額は産地卸→集散地卸→消費地卸で同一商品が重複計上されうる。飲食料品では全国計で卸売(52)83.7兆円・小売(58)39.1兆円、
比は約2.14（2020年、`0004003257`、2026-06-23 取得の値。記録は `references/verify_food_2020.md`）。他の産業では測っていない。
「卸売＞小売＝付加価値が大きい」ではない。教材で並べるなら注記必須。

## 効くケース
- 「○○（飲食料品/機械器具/織物衣服…）の卸売・小売 年間商品販売額、都道府県トップN」型の教材データ。
- 製造（姉妹レシピ）と並べて**製造→卸売→小売の流通段階比較**（階級区分図 `food_distribution_choropleth_p000` 参照）。

## 効かない/別レシピ

## このレシピを使うLLMへのヒント
1. **卸売/小売の構造統計は『経済センサス活動調査』で取る**（商業統計調査は2014年が最後）。
2. **商業表は指標が tab**（製造表は cat01）。`cdTab` で絞る — 調査群で軸が違う点に注意。
3. **規模 cat02=0(合計)・都道府県は area 5桁末尾000**（政令市除外）。
4. **VALUE単一→dict** を list 正規化。**47県合計=全国計**で検算（都道府県レベルのみ）。
6. limit を超えると `RESULT_INF.NEXT_KEY` が付き残りが返らない。fetch.py は NEXT_KEY があれば `TRUNCATED` で止める。
5. 「食料品」は製造(09)と商業(52/58)で**飲料の扱いが非対称**。範囲を揃える時は要注意。
